# پروژه EDA دیتاست Airbnb Open Data

این بسته شامل دو نوت‌بوک Jupyter، فایل داده اصلی و خروجی‌های پاک‌سازی‌شده است.

## ساختار پروژه

- `notebooks/01_extraction_cleaning.ipynb` — استخراج، شناخت داده، بررسی کیفیت، پاک‌سازی، مدیریت داده‌های پرت و مثال مقیاس‌دهی
- `notebooks/02_exploratory_analysis.ipynb` — آمار توصیفی، نمودارها، توزیع، همبستگی و آزمون‌های آماری
- `data/Airbnb_Open_Data.csv` — فایل اصلی دیتاست
- `data/airbnb_cleaned.csv` — خروجی پاک‌سازی‌شده نوت‌بوک اول
- `data/airbnb_price_analysis.csv` — آگهی‌های دارای قیمت معتبر

## نحوه اجرا

1. ZIP را استخراج کنید.
2. در ترمینال، وارد پوشه پروژه شوید.
3. کتابخانه‌های موردنیاز را نصب کنید:

   ```bash
   pip install pandas numpy matplotlib seaborn scipy scikit-learn jupyter
   ```

4. Jupyter را اجرا کنید:

   ```bash
   jupyter notebook
   ```

5. ابتدا `01_extraction_cleaning.ipynb` را از ابتدا تا انتها اجرا کنید.
6. سپس `02_exploratory_analysis.ipynb` را از ابتدا تا انتها اجرا کنید.

نوت‌بوک‌ها در این بسته اجرا و بررسی شده‌اند. برای بازتولید نتایج، بهتر است هر دو نوت‌بوک را در همان ترتیب بالا اجرا کنید.

## نکات روش‌شناختی

- ردیف‌های تکراری و شناسه‌های آگهی تکراری بررسی شده‌اند؛ تعداد حذف‌ها در خروجی نوت‌بوک اول گزارش می‌شود.
- قیمت‌ها از رشته به عدد تبدیل می‌شوند. قیمت گمشده برای تحلیل قیمت استفاده نمی‌شود.
- مقادیر نامعتبر در بعضی ستون‌های محدودشده به `NaN` تبدیل می‌شوند؛ کل آگهی صرفاً به همین علت حذف نمی‌شود.
- داده‌های پرت قیمت با روش IQR علامت‌گذاری می‌شوند، اما به‌صورت خودکار حذف نمی‌شوند.
- در تحلیل قیمت، تعداد نمونه استفاده‌شده در هر تحلیل گزارش می‌شود.
- آزمون‌های آماری باید همراه با اندازه اثر، حجم نمونه و محدودیت‌های داده تفسیر شوند.
- همبستگی به معنی علیت نیست.

## نکته مهم درباره تفسیر نتایج

این دیتاست ممکن است دارای خطاهای ثبت، داده‌های ناقص یا ویژگی‌های مصنوعی/غیرواقع‌گرایانه باشد. بنابراین پیش از نتیجه‌گیری درباره بازار واقعی Airbnb، الگوهای مشکوک را در داده‌ها بررسی کنید. نتایج این پروژه درباره همین فایل است و نباید بدون اعتبارسنجی به کل بازار تعمیم داده شود.
